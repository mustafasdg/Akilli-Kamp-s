# screens/

Navigation ağacına bağlanan **ekran (sayfa)** bileşenleri.

Planlanan ekranlar: `LoginScreen`, `RegisterScreen`, `AnnouncementsScreen`,
`MenuScreen`, `MapScreen` (ileride `react-native-maps`), `ProfileScreen`,
`ScheduleScreen`, `SettingsScreen`.

Ekranlar veriyi `hooks/` üzerinden çeker, UI'yı `components/` ile kurar.
